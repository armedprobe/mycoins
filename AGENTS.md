# mycoins

Учёт купленной криптовалюты: транзакции покупки/продажи, позиции, P&L.

## Инварианты

- Lazarus 4.8 + FPC 3.2.2, LCL, целевые платформы Win64 и macOS.
- Хранилище — SQLite через штатный `fcl-db` (`sqlite3conn`, `sqldb`).
- Если задачу решает известная стабильная библиотека - предложи её установку, 
  но самостоятельная "тихая" установка новых библиотек запрещена. 

## Модель

`spec/MODEL.md` — форматы хранения, расчёт P&L, именование, справочники.
`spec/schema.dbml` — схема БД, источник правды для DDL.
Любая правка денежных величин начинается с этих файлов.

## Границы слоёв

- `src/core` — модель, хранилище, расчёты. **Без LCL**: иначе юнит-тесты нельзя
  запускать консолью.
- `src/infra` — внешние API (CoinGecko), тоже без LCL.
- `src/ui` — формы LCL и только они.
- `test` — консольный проект на `fpc`, тестовый раннер `consoletestrunner`/`fpcunit`.

## Окружение (проверено на этой машине)

- `lazbuild.exe` и `fpc.exe` **не в PATH**. Полные пути:
  - `C:\lazarus\lazbuild.exe`
  - `C:\lazarus\fpc\3.2.2\bin\x86_64-win64\fpc.exe`
- Сборка без `.lpi`: `fpc -Mobjfpc -Sh -Fu<каталог юнитов> ...` (`-Sh` = `{$H+}`).
- GUI агент запускает только на своём мониторе (`spec/intent-agent-monitor.md`):
  `.\bin\mycoins.exe --monitor-at=$(.\tools\agent-point.ps1)`.
  У LCL `Process.MainWindowHandle` — скрытое окно `Application`, а не форма:
  окна формы искать через `EnumWindows` по pid.
